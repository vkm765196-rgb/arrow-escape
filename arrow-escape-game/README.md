# Arrow Escape / Clear the Board 🏹

A minimalist, satisfying mobile puzzle game where you clear tangled polyline arrows off the board. Arrows slither slowly and calmly around every 90° corner along their path!

## ✨ Features
- **1000 Procedurally Generated Levels**: Scale from relaxing 6-arrow warmups to 60+ arrow grandmaster mazes (Leaf Labyrinth, Heart Maze, Diamond, Matrix).
- **100% Solvable Guarantee**: Reverse-assembly generation ensures zero deadlocks.
- **Calm, Slow Slither Physics**: Watch arrows smoothly turn corners and round bends.
- **Mobile First & Responsive**: Optimized for phones and desktops alike with high-precision touch detection.
- **Celebration Screen**: 1:1 replica of the "Train Your Brain - Level Completed!" screen with confetti and miniature maze blueprints.
- **Procedural Sound FX**: Web Audio API melodic combos and wooden bonks.
